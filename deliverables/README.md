# 家长会 / 成绩分析材料

本目录存放基于本项目统计数据生成的成品材料，供归档与线下使用。

| 文件 | 说明 |
|---|---|
| `期中-月考成绩对比分析.xlsx` | 月考 vs 期中：每人每科分数、单科排名、名次升降、分数变化；含总览、总分、语文/数学/英语/专业课/发动机分表、科目统计、说明 |
| `24汽修高考班_期中家长会.pptx` | 家长会 21 页：成绩分析、单科讲评、家校配合、河北高职单招 vs 对口升学对比、近三年分数线、数据来源与核验 |
| `升学政策与分数线来源.md` | PPT 中政策与分数线的完整核验记录与官方网址清单 |

## 隐私说明

- `xlsx` 与 `pptx` 中含真实学生姓名与成绩，**默认不提交到 Git**（见根目录 `.gitignore`）。
- 部署到 EdgeOne 的网站只使用合成演示数据，不包含任何真实学生信息。
- 如需把材料一并入库，请先把学生姓名替换为学号/匿名编号，并确认仓库为私有。
